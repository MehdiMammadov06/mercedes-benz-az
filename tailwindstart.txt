TAILWIND CSS — İŞƏ SALMA QEYDLƏRİ (ABB layihələrindəki üsul)
=============================================================

Bu layihə Tailwind-i Vite plagini ilə YOX, ayrıca CLI ilə işlədir.
Mənbə fayl:        src/index.css   (buraya yazırsan)
Kompilyasiya:      src/output.css  (React bunu yükləyir, əl ilə redaktə ETMƏ)


İKİ TERMINAL AÇARAQ (tövsiyə olunan, prosesi öz gözünlə görürsən)
-----------------------------------------------------------------
Terminal 1 — Tailwind-i izləmə rejimində işə sal (ABB-dəki --watch kimi):

    npm run css

Terminal 2 — Vite dev serverini işə sal:

    npm run vite


BİR ƏMRLƏ (hər ikisini paralel işlədir)
---------------------------------------
    npm run dev

(bu, `concurrently` ilə həm CSS watch, həm Vite-i eyni anda işə salır)


CLI ƏMRİNİN TAM FORMASI (istinad üçün, ABB-dəki kimi)
-----------------------------------------------------
    npx @tailwindcss/cli -i ./src/index.css -o ./src/output.css --watch


BUILD (təhvil / deploy üçün)
----------------------------
    npm run build
    (əvvəlcə output.css-i kiçildilmiş yaradır, sonra vite build edir)
